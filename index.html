Dolmo

对方说的话，
译好挂在刘海上。

Dolmo 是 macOS 上的会议实时翻译。字幕显示在屏幕顶部的刘海岛里；打开「分享时隐藏」后，系统截图和录屏里看不到它。

即将推出，目前还在测试，暂不提供下载。

它能做什么

字幕在刘海里
对方的原文和译文一起显示在刘海岛上，不挡会议窗口。不用时，岛收成刘海两侧的一个小点。
回答建议
对方提问时，按你导入的简历或资料给出可以直接说的回答。只显示，不朗读。
截图和录屏拍不到字幕
打开「分享时隐藏」后，岛和字幕不会出现在 macOS 的截图和录屏里。Zoom、Meet 等会议软件的屏幕共享还在逐个验证，暂不保证，共享前请先预览。设置页和 iPhone 第二屏不受这个开关影响。
可以完全离线
在 Apple 芯片、macOS 26 的 Mac 上用系统自带的语音识别和翻译，语言资源下载好后，识别和翻译都在这台 Mac 上完成。也可以接云端服务；翻译和回答建议还能接本机的 Ollama 等模型。
记录保存在本机
每场会话的字幕保存在本机，可以搜索，导出 TXT 或 Markdown。每次开始保存时，岛上会提醒你先征得对方同意，一键就能不保存。用云端服务时，音频和文字会发给对应的服务；用 Soniox 识别时，导入资料里的术语也会在开始翻译时发过去；生成回答建议或纪要时，相关内容会发给你选的模型。
一个快捷键开始
检测到 Zoom、Teams、Meet 等通话时，岛上会提示「开始翻译」，按 ⌃⌥R 或点一下就开始。

需要什么

macOS 14 或更高。自动提示通话需要 macOS 14.4，离线模式需要 Apple 芯片和 macOS 26。用云端服务时，需要你自己的服务账号和 API key，key 只保存在本机。

Dolmo 基于 Mimi 开发（yuxino，MIT 许可）。
